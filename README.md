AI Data-Center Electrification — README
========================================

What this page covers
---------------------
A self-contained technical briefing on how electricity reaches AI silicon:
generation (offsite CCGT + grid HVAC/HVDC; onsite SOFC/MCFC/PAFC/PEM, turbines,
gensets, hybrids), hydrogen path math (why electrolysis + PEM is usually wrong
for baseload), site-boundary AC→DC conversion (legacy UPS/PDU/PSU vs SST /
~800 V DC), in-hall DC distribution to GPU/CPU voltage regulators, bottlenecks,
company map by hop with public tickers, pathway comparison table, and glossary.
